خطوات النشر على GitHub Pages
1) أنشئ حساباً على github.com ثم New repository (مثلاً: construction-app) واجعله Public.
2) Add file > Upload files، ثم ارفع الملفات الخمسة (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) واضغط Commit.
3) Settings > Pages > Source: Deploy from a branch > Branch: main / root > Save.
4) بعد دقيقة أو دقيقتين يظهر الرابط: https://اسمك.github.io/construction-app/
5) على الموبايل افتح الرابط: Chrome (أندرويد) ← «تثبيت التطبيق»، Safari (آيفون) ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
تنبيه: البيانات هنا تُحفظ في متصفح كل جهاز، ولا تُشارك بين الأجهزة. غيّر كلمة سر admin فور أول دخول.
